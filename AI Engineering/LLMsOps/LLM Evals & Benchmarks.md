# LLM Evals & Benchmarks

> **Mental Model:** In traditional software, unit tests assert deterministic outputs (`assert result == 42`). In AI engineering, LLMs are non-deterministic, so evaluation must be probabilistic and multi-dimensional. LLM Evals measure: (1) **Grounding & Faithfulness**, (2) **Answer Quality & Relevance**, and (3) **Regression Detection across prompt/model updates**.

| **The RAG Triad (Ragas Metrics)**     | The standard evaluation triangle measuring: (1) **Context Relevance** (did we retrieve the right chunks?), (2) **Groundedness / Faithfulness** (is the answer derived only from context?), and (3) **Answer Relevance** (did it answer the user's question?) | `Ragas`, `DeepEval`, `TruLens`                         | Score extraction per metric on 0.0–1.0 scale; sentence-level claim decomposition for faithfulness calculation            | ✅ Pinpoints the exact failure point (retrieval failure vs generator hallucination); automated scoring ❌ Relies on judge LLMs which can introduce scoring bias; slow to run on large production datasets | [Ragas Documentation](https://docs.ragas.io/), [DeepEval GitHub](https://github.com/confident-ai/deepeval) |
| **Context Precision & Recall**        | **Precision**: Are the top-ranked retrieved chunks actually relevant (penalizing low-quality noise at the top)? **Recall**: Did we retrieve all ground-truth information needed to formulate the answer?                                                     | `Ragas`, `TruLens`                                     | Mean Average Precision (mAP) calculation over chunk rankings, comparing ground truth sentences against retrieved context | ✅ Crucial for tuning chunk size, overlap, embedding models, and rerankers ❌ Requires human-curated golden test sets with labeled ground truth context to measure recall                                 | [Ragas Context Metrics](https://docs.ragas.io/en/latest/concepts/metrics/context_precision.html)           |
| **Semantic & Exact Matching Metrics** | Non-LLM deterministic similarity scoring comparing generated text against ground-truth references                                                                                                                                                            | `BERTScore`, `ROUGE-L`, `BLEU`, `Levenshtein` distance | Compute n-gram overlap (BLEU/ROUGE), token embedding similarity (BERTScore), string exact matches for numbers/dates      | ✅ 100% deterministic, free (zero LLM token cost), runs in milliseconds in CI/CD ❌ Poor proxy for human quality; penalizes valid answers phrased using synonyms or different stylistic formats           | [Hugging Face Evaluate](https://huggingface.co/docs/evaluate/index)                                        |

## LLM-as-a-Judge Architecture

| Topic / Skill                              | Core Concepts & Mental Model                                                                                                                                                      | Tools & Libraries                          | Key Techniques                                                                                                                                       | Tradeoffs & Failure Modes                                                                                                                                                                                                                | Resources                                                                                     |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Single-Answer Grading (Direct Scoring)** | A powerful frontier model (GPT-4o, Claude 3.5 Sonnet) acts as an evaluator, grading a generated response on a 1–5 rubric with explicit chain-of-thought rationale                 | `DeepEval`, `LangSmith Evals`, `Promptfoo` | Provide explicit evaluation rubrics, force reasoning explanation before the numerical score (`<thought>` $\rightarrow$ `<score>`), temperature = 0.0 | ✅ Highly correlated with human preferences; provides detailed qualitative feedback explaining why a score was given ❌ Model bias: judges favor wordier/longer responses (verbosity bias) and outputs generated by their own model family | [LLM-as-a-Judge Paper (Zheng et al.)](https://arxiv.org/abs/2306.05685)                       |
| **Pairwise Comparison (A/B Arena)**        | Presenting two model outputs (Model A vs Model B) to a judge LLM simultaneously and asking it to declare a winner or tie                                                          | `FastChat / LMSYS`, `DeepEval`             | Swap presentation order (run both A/B and B/A) to cancel position bias, strip model identity metadata                                                | ✅ More reliable than absolute 1–5 scoring; eliminates subjective scoring scale drift across different test runs ❌ Position bias (judges favor Option A over Option B); double LLM calls doubles evaluation cost                          | [LMSYS Chatbot Arena](https://chat.lmsys.org/)                                                |
| **Reference-Free vs Reference-Based**      | **Reference-Based**: Compares output against human-verified golden answers. **Reference-Free**: Evaluates output quality purely from context without needing pre-existing answers | `Ragas`, `UpTrain`                         | Reference-free for production monitoring (faithfulness, toxicity); reference-based for pre-deployment regression testing                             | ✅ Reference-free works on live production queries without human labeling ❌ Reference-free cannot determine if the answer missed external factual details absent from the prompt                                                          | [DeepEval Metrics Guide](https://docs.confident-ai.com/docs/measuring-llm-evaluation-metrics) |
