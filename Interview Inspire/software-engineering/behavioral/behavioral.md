# Behavioral & Engineering Leadership Interview Questions

---

## Ownership & Delivering Under Deadlines
1. **[Behavioral / HM]** How do you handle strict deadlines when backend API dependencies or contracts are delayed or changing?
2. **[Behavioral / HM]** Describe a high-stakes production incident or outage you were involved with: how did you troubleshoot, communicate, and prevent recurrence?
3. **[Behavioral / HM]** Tell me about a time you had to push back on product management regarding unrealistic timelines or accumulating technical debt.

---

## Technical Leadership, Mentorship & Code Standards
1. **[Behavioral / HM]** Describe an instance where you mentored a junior engineer or improved team-wide engineering practices (code reviews, testing standards, CI/CD).
2. **[Behavioral / HM]** How do you handle strong technical disagreements with peers regarding architecture or framework selection?
3. **[Behavioral / HM]** Tell me about a time you advocated for accessibility (a11y) or web performance when it was not explicitly prioritized in the product roadmap.

---

## Performance & System Impact
1. **[Behavioral / HM]** Can you give a concrete example of an existing feature where you measured and significantly improved runtime performance or Core Web Vitals?
2. **[Behavioral / HM]** Describe a scenario where you had to balance feature delivery speed against long-term scalability and maintainability.
